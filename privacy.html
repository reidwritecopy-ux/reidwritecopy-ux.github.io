Privacy policy

Last updated 23 September 2026

The short version: MIDAS has one user, its operator. It does not collect anything from anybody else, because nobody else uses it.

Who this covers

MIDAS is a private tool run by one person to publish videos to YouTube channels that person owns. It is not a product, a service or a website that members of the public sign in to. There are no accounts and no other users.

What it accesses

MIDAS uses Google's OAuth to obtain permission to act on its operator's own YouTube channels, using these permissions and no others:

  • youtube.upload — to upload a video file
  • youtube — to set a video's title, description, tags, category and thumbnail, and to read back what was uploaded to confirm it arrived

That permission is granted by the operator, to their own channels, in a browser. It is never requested from anybody else.

What it stores, and where

  • An OAuth token for each channel, kept as a file on the operator's own computer, readable only by that account. It is not sent anywhere, not synced, and not backed up off that machine.
  • A record of what was uploaded — the video's own id, title and upload time — kept alongside the video's files on the same machine.

Nothing is stored on a server. There is no database, no analytics, no tracking, and no third party with access to any of it.

What it does not do

  • It does not collect data about viewers, subscribers or commenters.
  • It does not read any other person's YouTube account, channel or data.
  • It does not sell, share, transfer or disclose YouTube API data to anyone.
  • It does not use YouTube API data for advertising, profiling or training any model.
  • It does not use YouTube API data to determine creditworthiness or for lending purposes.

Google API Services User Data Policy

MIDAS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How long anything is kept

Tokens are kept until they are revoked or replaced, and are deleted when a channel is no longer published to. Upload records are kept as part of the project's own files for as long as the project exists.

Revoking access

The operator can withdraw MIDAS's access at any time at myaccount.google.com/permissions, which immediately stops it being able to upload anything. Deleting the token files on the machine has the same effect locally.

Other people's material

Photographs used in videos come from public-domain and openly licensed sources, and every one is credited with its author and licence in the video's own description. No personal data of any kind is gathered from viewers.

Changes

If this policy changes, the date at the top changes with it.
